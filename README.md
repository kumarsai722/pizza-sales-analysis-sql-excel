# 📊 Pizza Sales Analysis using SQL & Excel

## 📌 Project Overview
This project analyzes pizza sales data to extract meaningful business insights related to sales performance and customer behavior.

---

## 🎯 Objective
- Understand sales trends  
- Identify top and low performing products  
- Analyze customer ordering patterns  
- Support data-driven business decisions  

---

## 📁 Dataset
The dataset contains:
- Order details (date, time, order_id)
- Product details (pizza name, category, size)
- Sales data (quantity, total_price)

---

## ⚙️ Tools & Technologies
- SQL (Data Analysis)
- Excel (Dashboard & Visualization)

---

## 📈 Key KPIs
- Total Revenue  
- Total Orders  
- Total Pizzas Sold  
- Average Order Value  
- Average Pizzas per Order  

---

## 🔍 Analysis Performed

### ⏱ Time-Based Analysis
- Daily order trends  
- Hourly order trends  

### 🍕 Product-Based Analysis
- Sales by category  
- Sales by size  
- Top 5 best-selling pizzas  
- Bottom 5 least-selling pizzas  

---



---

## 💡 Key Insights
- Peak sales during weekends (Friday & Saturday evenings)  
- Highest orders between 12–1 PM and evening hours  
- Large pizzas contribute the highest revenue  
- Classic category dominates sales  
- Some products consistently underperform  

---

## 🚀 Business Recommendations
- Increase staffing during peak hours  
- Promote high-performing categories  
- Improve or remove low-performing products  
- Introduce offers during low-demand periods  

---


## 📌 Conclusion
This project demonstrates how raw sales data can be transformed into actionable insights using SQL and Excel.
